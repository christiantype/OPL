The roll

 

Everyone in AHA, each with their own poster behind their name — read off the print file, so a name can never land on somebody else's work.

Roll

 

The whole roll fits inside it, so the pace follows from the count.

Type

Eunuverse Roman. One cap height across the whole roll — Size is the ceiling and the longest name decides, so nothing towers over anything else.

Tracking is in thousandths of an em, the way it is set in InDesign. The fit takes it into account, so opening the letters makes the type smaller rather than running it off the edge.

Colour

Every name turns the type further round the wheel. White and black have no hue to turn, so give the type a colour if you want the roll to change with it. At zero the roll holds one colour.

Poster

The posters are the 24 × 36 artwork, whole and never cropped — the caption band is trimmed off at the artwork edge. Show at zero leaves the frame to the type alone; Across and Down place it, and they run past the edges so it can bleed.
