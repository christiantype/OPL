Foundations

Principles

Six rules the whole Lab holds to. When a tool breaks one, it's the tool that's wrong — bring it back here.

One shell

Every tool loads tool.css last. It owns the theme and the geometry of every control, so no tool restyles a button or a slider.

Engineered, not decorated

IBM Plex sets the type; corners are square; one blue accent (#0f62fe) carries every interactive state. Function first, no ornament.

Light & legible

White chrome, dark controls. Every text and outline clears WCAG AA — muted grey is #525252, never lighter, and labels never fall below 10px.

Islands, not chrome

Controls live in white cards floating on the grey rail, on a 16px grid. No panels butt together, no bottom bars sit over the artwork.

The artboard is sacred

The canvas is a white board with a thin border on a grey mat — and never a drop shadow. The shell frames the art; it doesn't decorate it.

Plain language

Labels say what a control does — Width, Softness, Density. No math, no jargon, no zero-padded numbers.

Button & input ground

Corners

Carbon is square, and so is the Lab. Every radius token is zero — buttons, selects, inputs, islands, swatches. The only curves are the round slider thumb and the record dot.

Everything--r-* · 0
Slider thumb50% · the exception

Buttons and selects are square — 0 radius — everywhere, enforced !important so no tool can drift it. It's the fastest read of the whole system.

Spacing

A strict grid of multiples — 2, 8, 16, 24. Islands and their contents breathe on the same rhythm in every tool.

Slider stack · 2px — label to track
Control gap · 8px — rows inside an island
Island gap & padding · 16px — between and inside cards
Canvas mat · 24px — board inset from the rail

Layout frame: the rail is --rail 300px wide, the topbar --top 82px tall. These are the only geometry a tool defines itself.

Type

IBM Plex Sans runs the interface; IBM Plex Mono carries labels, readouts and code. Small caps for labels, tabular mono numerals for data.

Patterns

How the pieces come together — the shapes every tool is built from.

The artboard

A white board with a thin 1px border, centred on a grey mat with a 24px inset — and no drop shadow, ever. A tool may paint its own ground inside render() (cream, dark paper); the frame stays the same.

Rail of islands

Left rail, 300px, scrolls. Each logical section is its own island; the topbar carries the wordmark, the aspect selector sits top-right of the canvas. This is the frame — see the components above for the pieces.

Export

Record captures the canvas at 30fps to H.264 MP4 (WebM fallback); audio tools add the WebAudio track. Save writes a PNG. Both hide on-canvas edit handles first, and render to a fixed 1920-long-edge buffer for crisp output. The record dot shows while capturing.

Direct manipulation & performance

Where a tool places elements on the canvas, selection is unified — click to focus, drag to move, handles to resize, and edit UI hides during capture. Tools with an auto-morph / performance mode animate a chosen set of dials while recording, so the piece drifts between legible and abstract on its own.

Audit

A pass across all seventeen tools on the shell. The finding was consistent: the theme was right, but each tool carried its own copy of the control geometry — so headings, sliders and swatches had quietly drifted. The fix was to make tool.css the complete component layer, correct the tools that had leaked their old dark theme, then re-skin the whole system in the vein of IBM.

What this pass changed

  • IBM skinRe-skinned the whole shell in the vein of IBM. IBM Plex Sans + Plex Mono (self-hosted), square corners everywhere, one IBM-Blue accent for primary / selected / focus, neutral greys, an 8/16/24 grid, and a Carbon-style dark tooltip.
  • Addedtool.css is now the complete component layer. Slider geometry, group headings, colour rows, preset swatches and toggles were promoted out of the seventeen tools into one place, so they can no longer drift.
  • FixedHeadings unified. Every .group__t had its own tracking (.11 / .12 / .16em) and colour — now one heading spec, shell-wide.
  • FixedSpectral-Smear was rendering in its old dark theme — it self-applied body.dark tokens above the shell. Relit to match.
  • FixedDark leftovers cleared — Static's status pill & icon buttons, Garden-Variety's blue crop frame, and the dark tooltips in Windchime / Visual Poetry.
  • FixedAccessibility. Sub-10px control labels in Image-Train (down to 8px), Angel and Tape were raised to 10px; OPEN LAB's morph chips to 11px.
  • KeptIntentional exceptions. OPEN LAB's dark shape-preview chips stay dark inside the light shell. Fixed-output captures (open-reel, open-slots, scanner, lake-opeka, ships-in-the-night…) and the full-bleed Projection tool sit outside the shell by design.
