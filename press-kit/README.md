# Press — portfolio kit for more-than.design

Everything you need to present Press as an OP/AL flagship product.

## What's in here

| File | What it is |
|---|---|
| `copy.md` | Product positioning — name, taglines, descriptions (short/medium/long), and the eight feature callouts, each in two lengths. |
| `case-study-quiet-leaf.md` | The demo narrative — The Quiet Leaf story, structured as a portfolio case study with captions for each screenshot. |
| `shot-list.md` | Exact screenshots to take, in order, with staging steps so every frame looks intentional. |
| `press-section.html` | A self-contained HTML/CSS section you can open in a browser, adapt, or lift pieces from — matches a black-on-cream, typography-first aesthetic. |
| `features.json` | The same content as structured data, if the site is component-driven. |

## The live portfolio page

The working page is `projects/press.html` (data-driven, uses `shared/project.js`).
It's currently scaffolded from the copy in this kit with editorial section blocks;
swap those for `scenes`/`cards` mockups or real screenshots as they come in.
The project is registered in `projects.json` as **hidden** until the screenshots are shot.

## The demo client is already live

**The Quiet Leaf** (slug `quiet-leaf`) exists in Press right now — client, AI description,
brand kit (palette + five named text styles), a leaf mark in the header (Press × 🍃),
and three starter templates: *Tasting Notes*, *Weekly Steep*, *On the Menu*.

Two things only you can do before screenshots:

1. **Upload tea photography** into asset groups (shot list inside `shot-list.md` — pours,
   leaves & tins, the shop, hands & cups). Use your own/licensed imagery.
2. **Bake template thumbnails** — open each of the three templates once and hit
   Save Template; thumbnails generate on save.

Then follow `shot-list.md` top to bottom on the deployed site.
