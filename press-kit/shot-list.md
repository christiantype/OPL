# Shot list — staging The Quiet Leaf

Work on the **deployed site** (AI features live there). Browser at ~1440px wide,
100% zoom, light mode. Hide bookmarks bar. Use a clean incognito window logged in
as hi@opal.design.

## Stage 0 — prep (15–20 min, one time)

1. **Photos.** Gather 12–16 tea photos (your own or licensed). Warm, low-contrast,
   morning light. Upload at `/quiet-leaf/assets` into these groups (create categories):
   - **Pours** (4–5): kettle pours, steam, glass teapots
   - **Leaves & Tins** (3–4): dry leaf close-ups, tins, scoops
   - **The Shop** (3–4): shelves, counter, window light, a corner with a chair
   - **Hands & Cups** (3–4): hands cradling cups, tables from above
2. **Bake thumbnails.** Open each template (Tasting Notes, Weekly Steep, On the Menu)
   from `/quiet-leaf/templates` and hit **Save Template** once each.
3. **Optional but great:** connect a test Meta account, or use demo mode for the
   scheduling shots.

## The shots (in case-study order)

### 1 · Homepage / command bar
- URL: `/quiet-leaf`
- Wait for the typewriter placeholder to show a tea-flavored prompt (they generate
  from the description — e.g. "Announce Saturday's tasting…").
- **Capture:** full hero with PRESS × leaf header visible.

### 2 · Brand Kit — the system
- URL: `/quiet-leaf/brand-kit`
- **Capture A:** Color palette + Organization (leaf mark visible).
- **Capture B:** Text styles section — all five styles with previews.
- **Capture C:** Photo libraries grid (after Stage 0 uploads).

### 3 · Template in design mode — the rails
- Open **Weekly Steep** in design mode. Select the TITLE text.
- The "For creators, this element is…" panel shows **Editable field**.
- **Capture:** canvas + panel + Layers.

### 4 · Template in use mode — filling fields
- From Templates, use **On the Menu** as a post. Fields form on the left.
- Change the tea name to something seasonal ("First Flush Darjeeling").
- **Capture:** fields form + canvas.

### 5 · Create a post — the money shot
- … menu → **Create a post**. Type:
  *"Announce Saturday's golden hour oolong tasting — 4pm, twelve seats, reserve online."*
- Pick a template or Fresh layout → **Create post**.
- **Capture A:** the result card — chosen photo, the reason line, headline + caption.
- **Capture B:** after "Open in editor" — the composed canvas.

### 6 · Content Studio — the volume
- URL: `/quiet-leaf/studio`. Paste 6–8 lines of seasonal notes (tea names, tasting
  dates, one aphorism). Select all three templates → Generate.
- **Capture:** the studio mid-generation or the Drafts grid after.

### 7 · Version history
- In any editor session, make 6–8 moves, open **History**.
- **Capture:** the panel with labeled steps, one mid-timeline step selected.

### 8 · Recreate from screenshot
- Templates → New Template → upload one of your Figma JPGs (any brand — this shot
  is about the feature) → Recreate in Editor.
- **Capture:** the rebuilt canvas with the **Ref** overlay ON (40% ghost visible).

### 9 · Scheduling — the send
- Design/open a post → Schedule. For the carousel shot, use a Meta Carousel project
  with 3+ slides.
- **Capture A:** schedule modal with slide strip + "Schedule carousel · N slides".
- **Capture B:** `/quiet-leaf/schedule` queue with 2–3 upcoming posts (⌛ badge on
  the carousel).

### 10 · Multi-client — one roof
- URL: `/` (homepage with all clients).
- **Capture:** the client grid — ZLMC, Quiet Leaf, and the rest side by side.

## Style notes for the final images

- Crop browser chrome out except when the URL bar helps the story (shots 1, 10).
- Consistent padding when framing screenshots on the site; the tool is black-on-cream,
  so cream (#F4EFE6) or near-black mats both work.
- Pair each shot with its caption from `case-study-quiet-leaf.md`.
