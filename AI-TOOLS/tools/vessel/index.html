An expressive tool for JORDYN

You draw a shape with anchor points on a snap grid. Choose which points respond to the music. The shape lifts into 3D, casts a shadow, breathes with the track. One entity per song.

How it works:

  1. Pick a track and drop in an “ordinary” photograph
  2. Click to drop sharp anchors; click-and-drag to draw bezier curves with handles
  3. In Anchors, turn on which points react and pick a mode — Pulse, Bloat, Twist, Spike, Ripple, Shatter, Orbit
  4. Tune Drive and Sensitivity for extreme reactions. Press play. Export when it feels right.
