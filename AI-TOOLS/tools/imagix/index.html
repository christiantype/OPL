Imagix · Quick reference

Drop photos in. Pick a base Mode on the right. Sliders + value fields are bidirectional — slide or type a number. Re-roll rolls a fresh seed; Export PNG / SVG renders at the Output size.

Modes

  • Slice — cuts the canvas into parallel strips at any angle; each strip pulls a slice from one of your photos. Sliders: Count, Angle, Variation (uneven widths), Offset / Rotation / Scale jitter, Source pick (Random / In order / Alternating).
  • Dot — composites your photos to an underlay, samples the result at a grid, draws colored circles. Resolution / Spacing / Size / Grain / Image opacity (underlay strength) / Image blur (smooths colors).
  • Glyph — same grid sampling but the dot is a typed character or uploaded SVG/PNG. Type your own char or pick a preset; Upload glyph stamps an SVG or PNG at each cell, tinted by the sampled color.
  • Strata — hard horizontal bands, each band a different photo cover-fit. Bands · Height variation · Shift (slide left/right) · Gap · Shift mode (Alternate / Random / Cascade).
  • Scatter — photos as squares with optional connecting trails. Drag a square on the canvas to move; per-image numeric fields edit it precisely. Each photo gets a subject point auto-detected (saliency + chroma); trails anchor there, not the bounding box.
  • Window — one bold character (or several) carved into the canvas, photo shows through it. Shape · Count · Size · Position jitter.
  • Echo — each photo repeated N times with offset + decreasing opacity. Direction is set by Offset X / Y; Scale step grows or shrinks each echo.
  • Grid — asymmetric magazine grid; cells span varied units, each filled with one photo cover-fit. Density · Asymmetry · Gap.

Effect Layer

A Dot or Glyph overlay whose colors are sampled from the just-rendered base composition. With no points it covers the whole canvas. Click anywhere on the canvas to drop a point — the layer is then confined to those circular pools with the Brush radius + Falloff you set. Drag a point to move; Shift-click or use × in the list to remove.

Tip: turn the base into something visual (Slice / Strata / Scatter), enable the layer, set Dot size small + Sample blur high → soft halftone fragments that adopt the base colors.

Scatter — Trails

The connective bit. Each photo's subject point gets used as a graph node; trails connect them.

  • Connect — Chain (in add-order) · Near 2 / Near 3 (each photo to its N nearest) · MST (Prim's minimum spanning tree) · All (every pair).
  • Anchor — Square center (geometric) or Subject (line attaches to what the photo is about).
  • Style — Straight · Curved (bows perpendicular) · Dashed · Wavy (sin wave).
  • Color — Solid picker, or Subject gradient where each line gradients from one endpoint's subject color to the other.
  • Subject markers — Dot / Ring / Crosshair stamped on each subject point so the anchors are visible.

Output

Export size is in pixels. PNG rasterizes the full composition (base + effect layer). SVG exports the layer fragments as vector circles / glyphs when the layer is on (or the Dot mode as vectors when not). Slice / Strata / Scatter / Window / Echo / Grid bases are photographic and stay raster — use PNG for those.

Filenames include the seed so you can re-find a look later by re-typing the seed (coming soon — for now, screenshot the seed shown top-right).

Shortcuts

  • Drop files anywhere on the window to add photos.
  • Click an image thumbnail to toggle it off / on (without removing).
  • × on a thumbnail removes it; Clear all wipes the source list.
  • Type a number in any value field next to a slider; Enter or Tab to commit.
